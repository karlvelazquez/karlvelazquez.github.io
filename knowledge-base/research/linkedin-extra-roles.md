## Opdefi — DeFi Research & Backend Dev Extern (Jan 2023, 1 month, remote)

Opdefi placed Karl in decentralized finance (DeFi) research and backend work. For context:
- **DeFi** ("decentralized finance") refers to financial applications built on public blockchains (mainly Ethereum) that let people trade, lend, borrow, and provide liquidity without a traditional bank or broker as intermediary — the logic runs in self-executing "smart contracts" instead.
- **Gas** is the fee paid to the Ethereum network to execute a transaction or smart contract — a core concept anyone building on Ethereum has to understand, since it affects both cost and design (batching operations, gas optimization, etc.).
- **ERC20** is the standard interface that most fungible tokens on Ethereum implement (balanceOf, transfer, approve, etc.), making tokens interoperable across wallets and apps.
- **Uniswap** and **Curve** are two of the largest decentralized exchange (DEX) protocols. Uniswap pioneered the "automated market maker" (AMM) model, using liquidity pools and a constant-product formula instead of an order book. Curve is an AMM specialized for trading assets that should trade near parity with each other (e.g., stablecoins like USDC/DAI, or wrapped versions of the same asset), using a different, flatter pricing curve optimized for low slippage between similar-value assets. **Convex** is a protocol built on top of Curve that lets liquidity providers boost their yield from Curve deposits.
- Karl's listed work — implementing Uniswap/Curve interactions via **ABIs** (Application Binary Interfaces, the contract's callable-function spec), **typechain** (generates TypeScript types from contract ABIs), and **ethers.js** (a JS/TS library for talking to Ethereum) — is standard tooling for a backend engineer integrating with DeFi protocols. Testing via **Mocha** plus **Foundry** local chain forks (Foundry can fork mainnet state locally so you can test against real, live contract state without spending real gas) is also a standard, fairly sophisticated DeFi-dev testing setup for the time (early 2023, during the post-2022 "DeFi winter" when Curve/Convex's "Curve Wars" dynamics were a major topic in the space).

## Raspberry Pi DNS Sinkhole (Apr 2021, personal project)

Karl configured a Raspberry Pi 4 Model B to intercept outgoing DNS requests and return null/blocked responses for known ad- and malware-serving domains — i.e., a homemade version of the well-known **Pi-hole** pattern (Pi-hole is the most popular open-source implementation of exactly this idea: a Raspberry Pi running as a network-wide DNS sinkhole/ad-blocker, so every device on the home network gets ad- and tracker-blocking without installing anything on individual devices). This is a well-trodden hobbyist-networking project, but doing it from scratch (rather than just installing Pi-hole) suggests Karl built or substantially customized the DNS-filtering logic and domain blocklist himself, consistent with his broader "build things from fairly low-level primitives" pattern seen later at Oculo Health.
